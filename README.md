# FMCG Distribution — Business-first

Repository sản phẩm dành cho solo developer. Bộ đặc tả nghiệp vụ độc lập công nghệ sẽ được xây dựng qua PR B01 (nghiệp vụ) và B02 (công thức, dữ liệu mẫu, nghiệm thu).

> Trạng thái: bootstrap repository, **chưa phê duyệt Business Baseline mới**. Nguồn nghiên cứu được lưu lịch sử tại [research-sme-phan-phoi-hang-tieu-dung](https://github.com/chung6a8m/research-sme-phan-phoi-hang-tieu-dung).

Không suy đồng nhất tài liệu đã phê duyệt với phần mềm đã kiểm chứng hay quyền Go-Live.
